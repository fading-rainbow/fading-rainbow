# 工程案例

这些案例用于介绍现有项目的结构与工程问题。生产源码仓库保持私有；本文不包含凭据、客户数据、部署地址或线上规模声明。整理日期为 2026-09-10，不表示本轮重新验收了生产服务。

## Mon_Token：开源 AI 网关的定制与维护

**基础：** [Wei-Shaw/sub2api](https://github.com/Wei-Shaw/sub2api)，Go / Vue 3 / PostgreSQL / Redis。

**问题：** 多上游服务中，请求模型、实际上游模型和计费模型可能不同；并发、配额和流式响应又有不同的失败条件。

**工作内容：** 在上游基础上进行界面与运营能力定制，梳理模型映射与计费语义，维护并发/RPM、请求排队、错误分类和可观测性。上线流程强调显式镜像、健康检查和可回滚发布。

**面试切入点：** 如何区分真正限流与基础设施故障；为什么服务端 HTTP 200 不等于客户端收到了完整流；配额如何避免重复扣减；如何在小内存机器上安排构建与部署。

**贡献边界：** 网关基础能力来自 Sub2API，项目属于二次开发、集成和运维；不能将上游全部能力表述为个人从零实现。本轮仅检查本地仓库与项目说明，未修改或部署生产代码。

## Mon_Foree：跨平台客户端与控制平面

**组件：** Go / PostgreSQL / Next.js / Kotlin / WPF/.NET 8；采用 Xray、Wintun 等现有网络组件。

**问题：** GUI 生命周期与高权限网络操作不同步时，容易出现残留进程、网卡、路由或无法恢复的连接状态。

**工作内容：** 通过受限 named-pipe IPC 分离 Windows GUI 与系统服务，维护连接状态机、凭据保护、资源租约、诊断和恢复流程；Android 侧整合 VpnService 与隧道组件；控制平面管理设备与线路授权。

**面试切入点：** 权限边界为什么这样划分；如何确定资源归属；怎样处理崩溃和重复清理；如何将应用状态、操作系统资源和真实连通性分别验收。

**验证边界：** 现有项目说明中的发布版本和线上验收记录是历史快照，本轮未重新运行需要管理员权限的网络测试，也未查询或修改 VPS。

## Windows OCR 字幕翻译工具

**组件：** Python / mss / Pillow / Tesseract / requests / Tkinter / pystray。

**数据流：** 快捷键触发 → 指定屏幕区域截图 → 图像预处理和 OCR → 术语约束翻译 → 鼠标穿透覆盖层。

**工程重点：** 将 OCR 和网络调用放在需要时执行，处理屏幕坐标、线程通信、API 超时、UAC 环境变量与退出路径。项目不修改游戏文件或读取游戏进程内存。

**验证边界：** 本轮源码解析与配置检查不等于游戏内 OCR、延迟和覆盖层验收；不提供未经测量的性能数字。
